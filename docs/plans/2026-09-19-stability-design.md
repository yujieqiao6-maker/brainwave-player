# V8 稳定性与流畅度优化

目标：保留现有四个功能页和六种平滑算法，解决串口解析、断线状态、界面刷新与长时间录制的问题。

方案比较：仅限制绘图频率改动小但保留解析错误；整体重写会增加迁移风险；本次选择对现有单文件程序做定向修复。

1. 串口：完整读取长度+4字节的数据包，校验后解析，处理分片、粘包、未知字段和字段顺序；停止请求由工作线程收尾，避免界面阻塞。设备无有效注意力数据3秒即失效。标准模式不将原始脑电波转换为注意力；保留显式旧版兼容开关。
2. 界面：限制数据通知、日志、统计和绘图刷新频率，限制内存中的调试/预览条数。真正使用独立速度轴。补齐未加入布局的文件名与阈值控件。
3. 播放：断线/失效立即暂停并清除旧平滑状态；手动暂停后不会被下一条数据自动恢复。
4. 录制：完整CSV持续写盘，内存仅保留最近200条预览；浮点累计统计避免每条数据遍历全部历史。失败时清理状态并提示。

验证：unittest覆盖串口流解析和线程停止、长时间录制、失效/暂停行为；使用离屏Qt验证界面，最终启动真实窗口。硬件实测结果单独说明。

## 完成验证

- 34项离屏回归测试通过：串口拆包/粘包/校验与退出、六种平滑算法失效重置、暂停保持、10,000条CSV完整性、有界日志、写入/flush错误、设置恢复、断开时排队消息、错误弹窗中的嵌套事件。
- 真实QThread配合本地PTY虚拟串口验证：有效数据→坏信号→恢复→3秒超时→正常退出。
- 窗口与本地测试视频已验证可打开和播放；后续实体设备验证结果见下方小节，旧版兼容模式尚未实机验证。
- 数据通知合并至最高20Hz（失效通知立即发送），CSV保存实际送入播放器的控制数据；原始包导出保留最近2,000包，录制预览保留最近200行。CSV文件不受预览条数限制。
- 串口格式核对来源：https://developer.neurosky.com/docs/doku.php?id=thinkgear_communications_protocol
- 修改前源码已在项目目录外完成本地备份，备份不随仓库发布。

## 后续实体设备验证

实体设备使用9600波特率验证了标准Attention与Poor Signal字段解析，旧版兼容模式保持关闭。测试覆盖自动播放、随注意力改变播放速度和无效样本触发暂停。另修正未加载视频时信号恢复后残留的无效提示，新增2项回归通过。硬件实测不代表所有型号设备均已兼容。
